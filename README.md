# IT AI ML AI & Cybersecurity website

An editorial, responsive static website implementation based on `AI_Cybersecurity_Reference_Inspired_Website_Master_Prompt.docx`. It uses buildless HTML, CSS and JavaScript so it can be opened locally without a dependency install.

## Run locally

Open `index.html` directly, or serve the folder with any static server. Hash routes include `/`, `/about`, `/services`, `/services/[slug]`, `/projects`, `/projects/[slug]`, `/insights`, `/careers`, `/technologies`, `/team` and `/contact`.

## Content safety

Company-specific content is intentionally marked as illustrative or pending approval. Replace the placeholder contact details, project evidence, imagery, certifications, people and metrics before launch. The contact form currently demonstrates client-side states only and is not connected to a backend.
